# Atentiv

This directory is the canonical Atentiv implementation.

- Source code: `src/`, `libraries/`, `model/`, `public/`, and `tests/`
- Build and verification: `npm test`, then `npm run build`
- Loadable Chromium MV3 extension: `extension/`

The formal pages are `sidepanel.html`, `dashboard.html`, and `options.html`. The previous generated-only package is preserved under `archive/packaged-runtime-pre-source/` and is not part of the build.

See [repository inventory](docs/architecture/REPOSITORY_INVENTORY.md), [consolidation report](docs/architecture/CONSOLIDATION_REPORT.md), and [delivery report](docs/architecture/FINAL_DELIVERY_REPORT.md).
